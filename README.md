# Mayukh Ghosh — Portfolio

Personal portfolio site, built as a single self-contained `index.html` (no build step, no dependencies to install).

**Live site:** _add your GitHub Pages URL here once deployed, e.g. `https://maecdwbg.github.io/portfolio/`_

## Contents

- `index.html` — the entire site (HTML, CSS, JS, and the profile photo, embedded as base64)

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Set **Branch** to `main` and folder to `/ (root)`.
5. Save. Your site will be live at `https://<username>.github.io/<repo-name>/` within a minute or two.

## Updating content

All content lives directly in `index.html` — summary, experience, projects, skills, education, and certifications are plain HTML in clearly labeled `<section>` blocks. Edit the text directly and push to update the live site.

## Tech

Plain HTML/CSS/JS. Fonts loaded from Google Fonts (Space Grotesk, IBM Plex Sans, IBM Plex Mono). No frameworks, no build tools.
